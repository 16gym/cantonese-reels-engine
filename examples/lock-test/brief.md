# Lock test

A 15-second film whose only job is to prove the engine holds everything still.

Two people, one cha chaan teng, three clips: the booth, the drinks bar, back to the booth.
The third clip is a separate generation that must match the first: same faces, same clothes, same glass, same booth, same voices.

`story.json`, `bible.json` and `shots.json` in this folder are a proposed plan. The user may change any of it at the gates.
To use them: create the episode, then copy each file in when its gate starts.

Pass means the user answers yes to all four:

1. The Cantonese sounds like Hong Kong people talking.
2. Each person has the same voice in every clip.
3. Faces, clothes and the glass of lemon tea do not change between clips.
4. When the camera comes back to the booth, it is the same booth.

Write their verdict on each into `docs/DECISIONS.md` under "Your standing decisions".
